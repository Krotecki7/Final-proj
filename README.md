# Ваш дневник

## Зависимости проекта
Все зависимости находятся в файле requirements.txt
Для установки введите команду: pip install --no-cache-dir -r requirements.txt

### Запуск проекта

1. Перейдите на официальный сайт Docker и скачайте Docker Desktop для вашей операционной системы: https://www.docker.com/products/docker-desktop.
2. Установите Docker на свой компьютер
3. Проверьте, что Docker работает корректно командной docker --version в командной строке, которая должна показать Вам текущую версию 
4. Запустите файл redis-server.exe
5. Перейдите в текущую директорию проекта.
6. Запустите команду: docker-compose up -d

### Проверка работоспособности

- **Бэкенд**: Откройте браузер и перейдите по адресу `http://127.0.0.1:8000/`.
- **PostgreSQL**: Подключитесь к базе данных через pgAdmin или другой клиент.
- **Redis**: Используйте `redis-cli` для проверки подключения.

### Структура проекта

- Корневой каталог - Final-proj
- Пакет *config* содержит настройки проекта
- Пакет *diary* содержит основные функции приложения
- Директория *media* содержит все медиафайлы проекта
- Директория *static* содержит стили и скрипты Bootstrap для шаблонов
- Пакет *users* содержит функионал для авторизации, входа и выхода пользователей из приложения
- Файл [.env.example](.env.example) содержит информацию о скрытых данных, требующихся при запуске
- [docker-compose.yml](docker-compose.yml) конфигурационный файл в формате YAML, который описывает инфраструктуру проекта
- [Dockerfile](Dockerfile) текстовый файл с инструкциями для сборки образа Docker
- [manage.py](manage.py) управляющий файл в проекте на фреймворке Django
- [requirements.txt](requirements.txt) файл с зависимостями проекта
